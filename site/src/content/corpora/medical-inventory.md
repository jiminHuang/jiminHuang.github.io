This inventory contains a set of terms that are relevant to the study of medical history. The inventory is organised as a set of "heading terms" (around 175,000). Each heading term, which belongs to one or more of seven different semantic categories (shown in Table 1), is accompanied a set of semantically-related terms. These related terms have been automatically extracted using text mining methods from large collections of published medical text, dating from 1840 to the present day.
