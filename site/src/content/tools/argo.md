Argo is a web-based workbench for **building, sharing, and running** text-mining workflows. Users assemble pipelines from a library of pre-built processing components — tokenisers, taggers, parsers, named-entity recognisers — connect them on a visual canvas, and run the result on their own documents.

It was designed to make NLP **composable** across labs: a Manchester component and a Tokyo component can sit in the same pipeline without re-implementation. Workflows can be exposed as RESTful services, shared with collaborators, or embedded into other tools.
