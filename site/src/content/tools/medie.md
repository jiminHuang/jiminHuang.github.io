MEDIE is a **semantic retrieval engine** for MEDLINE. Instead of matching strings, it indexes sentences by their predicate-argument structure produced by the Enju parser, so you can search for **"X activates Y"** rather than the literal substring.

It's a research-grade tool used to build evidence summaries when keyword search returns too much noise.
